### 🎥 Jetson 카메라 비전 응용 서비스 · 실습 과제 1~6
`2026.10.29 ~ 10.31` · `부트캠프 실습 과제` · `개인 (Jetson team4)`

강의실에 IP 카메라와 웹캠 2대를 달고, **재실 인원 세기 + 장비 앞 근접 경고**를 Jetson 한 대에서 12시간 무중단으로 돌렸습니다. 영상은 보드 밖으로 내보내지 않고 숫자만 MQTT·REST로 냅니다.

**🙋 내가 한 일**
- **과제 1 카메라 연동**: 실습 키트가 없어 공용 카메라 리더(`camlib.py`, 최신 1장만 남기고 끊기면 자동 재연결)와 지연 측정 도구를 직접 만듦
- **과제 2 물체 인식**: YOLO11 PyTorch · TensorRT FP16 · INT8 · 큰 모델 속도·정확도·전력 비교, 조명 × 거리별 신뢰도 측정
- **과제 3 재실 인원 카운터**: 구역 그리기, 직접 계수 vs 문 출입 계수 비교, MQTT retain 발행
- **과제 4 행동 패턴 인식**: 17관절 포즈로 규칙 동작 판정, 다수결 안정화로 깜빡임 제거
- **과제 5 스테레오 거리 측정**: 웹캠 2대 보정(재투영 0.144px), 사람까지 거리 측정
- **과제 6 응용 서비스**: 위 기능을 묶어 `systemd` 서비스로 12시간 운영, 다른 팀용 결과 형식 문서 작성

**🛠 사용한 언어·도구**: Python · OpenCV (StereoSGBM, 카메라 보정) · Ultralytics YOLO11 · YOLO pose · TensorRT (FP16/INT8) · FFmpeg/GStreamer · RTSP · MQTT · REST · systemd · Jetson Orin Nano

**📈 결과**
| 항목 | 결과 |
|---|---|
| TensorRT FP16 추론 | **4.0ms** (PyTorch 25.2ms 대비 6.3배, 정확도 차이 0.004) |
| 스테레오 거리 오차 | 1~2m **±3.2% 이내**, 4m **+5.6%** (기준 12%) |
| 12시간 무중단 | health ok **100%**, 재시작 0회, 영상 저장 0건 |
| 카메라 1대 분리 | 3초 만에 감지, 다시 꽂으면 8초 만에 자동 복구 |
| 재부팅 후 복귀 | 서비스 18초, 카메라 3대 28초 |

**🧗 어려웠던 점 → 해결**
| 어려웠던 점 | 해결 방법 |
|---|---|
| IP 카메라 화면이 2분 만에 **105초나 밀림** | 버퍼에 프레임이 쌓이는 것이 원인 → 별도 스레드가 최신 1장만 남기는 리더로 바꿔 **1~2초 이내**로 고정 |
| INT8이 더 빠를 줄 알았는데 이득이 작음 | 직접 재 보니 0.7ms 빨라지고 정확도는 4.5% 떨어짐 → FP16을 기본으로 결정 |
| 먼 자리의 작은 사람을 못 잡음 | 960 입력 + 2×2 타일로 나눠 추론 → 1명 → 4~5명(실제 약 5명) |
| 모니터에 가려진 사람을 놓침 | 판정 방식을 바꿔 2명 구간 정확도 **39% → 56%** |
| 만세 동작에서 라벨이 깜빡임(9번) | 0.6초 다수결 안정화로 **0번** (지연 0.31초) |
| 먼 거리(4m) 스테레오 오차가 큼(-8.6%) | 체커보드를 먼 거리까지 고루 찍어 보정 → **1.7% 이내** |
| 인원 정확도 목표(MAE 1.0)는 미달(1.77) | 원인(타일 경계 중복, 감시 안 한 뒷문)을 분석해 개선 계획까지 정리 |

**📚 더 배우려고 찾아본 것**: 카메라 버퍼와 지연 원인(V4L2 vs RTSP), TensorRT 양자화(INT8)의 득실, 스테레오 카메라 보정·정렬 원리, 다른 팀이 바로 쓸 수 있는 MQTT/REST 결과 형식 설계

### 📷 Jetson 멀티모달 검색 · EmbeddingGemma 2 실습
`2026.10.23 ~ 10.28` · `부트캠프 실습 (10단계)` · `개인 (9단계 개선은 팀원 결과 참고)`

**🙋 내가 한 일**
- Jetson에 실습 환경을 따로 만들고 텍스트·이미지·음성을 한 공간에 넣는 임베딩 모델 설치
- 텍스트·이미지·음성 검색 실험과 단계별 속도·GPU 메모리 측정
- 학습 데이터를 직접 만들어 미세 조정, IP 카메라 물체 검색, 동작 인식 모델 학습
- **10단계: 카메라 2대로 강의실 접근 감지** — 두 카메라 위치 보정(교차 검증 오차 0.4~2.4cm), 삼각측량으로 사람 위치 계산, "빨간 미키마우스 쓰레기통" 같은 글로 정한 물건에 다가가면 알람

**🛠 사용한 언어·도구**: Python · PyTorch · sentence-transformers · EmbeddingGemma 2 · YOLO / YOLOE · GRU · ffmpeg · IP 카메라(RTSP) · Jetson Orin Nano

**🧗 어려웠던 점 → 해결**
| 어려웠던 점 | 해결 방법 |
|---|---|
| IP 카메라가 학교 와이파이에 안 붙음 | 카메라를 **Jetson 랜 포트에 직접 연결**하고 Jetson이 주소를 나눠 주게 함 |
| 라이브러리 충돌(torchaudio), 동영상 도구가 Jetson과 안 맞음 | 충돌 패키지 제거, 동영상 대신 사진으로 대체(자료에서 허용) |
| 미세 조정용 공식 데이터가 없음 | 학습 **303쌍**·평가 60쌍을 직접 만들어 학습 → acc@1 **0.833 → 0.850** |
| 3 epoch에서 성능이 떨어짐 | 과적합으로 보고 가장 좋았던 2 epoch 선택 |
| YOLO가 오리 인형을 곰 인형으로 인식 | 재라벨·YOLOE를 비교해 YOLOE가 가장 적합하다고 결론 |
| 동작 인식이 너무 자주 울림(만세 14번) | 결과를 평활화해 **3번**으로 정확하게 |
| 둘째 카메라에서 서 있는 사람 어깨가 화면 밖이라 검출 0건 | 카메라를 옮기고 기울인 뒤 다시 보정 |
| 카메라 한 대만 볼 때 앉은 사람을 서 있는 사람으로 착각해 오경보 | 한 대만 보는 추정은 알람에서 빼고, 같은 알람은 5초 안에 중복 생략 → 먼 사람 오경보 **0건** |
| GPU가 갑자기 안 잡힘(cuda False) | CPU로 도는 판(`proximity_app_cpu.py`)을 따로 만들어 실험 계속 |

**📚 더 배우려고 찾아본 것**: 멀티모달 임베딩 원리(텍스트·이미지·음성을 같은 공간에), 임베딩 차원 줄이기(768 → 256 → 128), 검색 평가 지표(acc@1·ndcg@10), 카메라 보정과 삼각측량(재투영 오차)

| 어려웠던 점 | 해결 방법 |
|---|---|

| 공용 DB에 쓰기 권한이 없음 | 내 계정 전용 InfluxDB를 sudo 없이 직접 설치·자동 시작 |
| 같은 메시지가 두 번 옴(5.6%) | 5초 안 중복 제거 규칙 추가 |
| 모델이 단순 기준선보다 나쁨 | 9월과 10월 데이터 분포가 다른 것을 찾아 '변화량 예측'으로 바꿔 해결 |
| TensorRT에서만 경보가 15% 틀림 | 하나씩 바꿔 추적 → 배열 메모리 순서 문제, 고쳐서 **0%** |

**🛠 사용한 언어·도구**: R · Brown 이중지수평활 · 요인분석 · 회귀분석 · KOSIS · e-지방지표

| 어려웠던 점 | 해결 방법 |
